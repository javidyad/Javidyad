# Javidnam Poster Maker

A one-page web tool that turns a portrait photo and a name into a printable memorial poster for people killed during Iran's nationwide protests in January. It is built for the ceremony on **7 November 2026 (16 Aban) at the Paulskirche in Frankfurt**, where Prince Reza Pahlavi accepts the Friedrich Naumann Foundation's 2026 Freedom Prize on behalf of the Iranian people. People print the posters and hold them up, so they must read clearly in photos and videos.

The owner speaks Persian. Reply to him in Persian unless he writes in another language. Code, comments and commit messages stay in English.

## Files

| Path | What it is |
|---|---|
| `index.html` | The whole app: markup, CSS and JS in one file. No build step. |
| `Template.jpg` | English poster background (about 4213 × 5953 px). Defines the coordinate space. |
| `Template-de.jpg` | German poster background, same layout and size. Generated by `tools/make_template_de.py`. |
| `Lion_and_Sun.png` | Emblem on the language screen, header and favicon. |
| `fonts/` (optional) | Self-hosted fonts: `ArchivoBlack-Regular.woff2/.ttf`, `Vazirmatn-Regular/Bold.woff2/.ttf`. The page falls back to system fonts if missing. |
| `lib/jspdf.umd.min.js` (optional) | jsPDF 2.5.1. Falls back to cdnjs if missing. |
| `tools/make_template_de.py` | Rebuilds `Template-de.jpg` from `Template.jpg` (see its docstring). |
| `LICENSE` | All rights reserved. The repo is public so people can read the code, not reuse it. |

Hosted as static files on GitHub Pages. Everything runs in the browser.

## Hard rules

- **No red in the UI.** The owner's community is monarchist and reads red as a leftist colour. The palette is navy `#1b2a4a` and gold `#b98a1f` (dark mode: gold `#d9ae45` on navy `#1c2030`). Red inside the poster templates themselves is part of the existing design and stays.
- **Privacy is a promise shown on the page.** Photos never leave the device. No uploads, no analytics, no trackers, no third-party scripts beyond fonts and jsPDF (which should be self-hosted). Some users may be in or connected to Iran.
- **Public code, not open source.** The repo is public and the page footer links to it (`sourceNote` / `sourceLink`) so people can check the privacy promise. Do not call it "open source" and do not add an open-source licence: the owner does not want others to copy or republish it.
- **Names are English letters only** (`A-Z a-z space . ' ’ -`), max 40 characters. The name is drawn in Archivo Black.
- **Two separate language settings:**
  - UI language: English or Persian (Persian is RTL, Vazirmatn). Chosen on the first screen, switchable with the header button. All strings live in `STR.en` / `STR.fa`; every key must exist in both.
  - Poster language: English (`Template.jpg`) or German (`Template-de.jpg`). Remembered in `localStorage` key `posterLang`.
- **Coordinates:** every number in `CONFIG` (photo box, name zone) is in the pixel space of the English `Template.jpg`. Any template is stretched to that size (`design.w/h`), so a new template only needs the same aspect ratio and layout. If `Template.jpg` is ever replaced with a different size, scale `CONFIG` with it.
- **German text must be checked by a native speaker** before printing. Current copy: `SAGT ES DER WELT` / `IM IRAN GETÖTET` / `BEI DEN LANDESWEITEN PROTESTEN IM JANUAR` / `FRANKFURT • 7. NOVEMBER`.
- The red German line must stay the same height as the English one (it was once made smaller and the owner rejected it: posters are read from a distance).

## How the page behaves

1. Language screen (emblem, English / فارسی), centred.
2. Form: poster language, photo picker (with privacy note), preview, zoom slider, name, PDF paper size (A3/A4), buttons.
3. Before any photo or name, the preview shows a small sample poster with a ghosted photo frame and `Firstname Lastname`. These placeholders are preview-only and never exported.
4. Photo: drag to move, pinch / wheel / slider to zoom (1–3×), arrow keys and +/- when the preview has focus. Default framing sits 30 % from the top (`focusY`) so faces are not cut.
5. Output:
   - **Save to gallery**: share sheet with a ~9 MP JPEG; falls back to a full-screen image the user long-presses to save (in-app browsers).
   - **Download JPG**: full size, capped at 16 MP for iOS.
   - **Download print PDF**: A3 or A4, image centred.

## Working on it

- No build: edit `index.html`, open it through a local server (`python -m http.server`), not `file://` (canvas export breaks).
- After any change, check: JS has no syntax errors, every `$('id')` exists, every `data-i18n` key exists in both languages.
- Test on a real iPhone and Android phone before publishing anything user-facing, including from inside Instagram / Telegram in-app browsers.
- Freeze changes around 3 November 2026; after that only fixes.

## Open items

- Put the self-hosted fonts in `fonts/` and jsPDF in `lib/` (sources: Google Fonts / the Vazirmatn GitHub releases / cdnjs).
- Set `og:image` to the full `https://` URL of `Lion_and_Sun.png` so link previews work.
- Rebuild `Template-de.jpg` from the full-resolution `Template.jpg` (the current one was made from a 1823 px copy, so the flag and photo are upscaled; the text is sharp):
  `python tools/make_template_de.py --template Template.jpg --fonts "C:/Windows/Fonts" --out Template-de.jpg`
  The Franklin Gothic fonts come with Microsoft Office on the owner's Windows PC. They are not in cloud sessions (claude.ai/code), and must not be committed to the repo (licence). Run this script on the owner's PC, or ask him to.
- Ideas the owner has not approved yet: story/square export, caption copy button, a second host as a backup link, a bigger multi-template platform after the event.
